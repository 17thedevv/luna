## Tải xuống

Bản hiện tại là **0.1.0-alpha.1**, một bản alpha prerelease. Chưa phát hành stable `0.1.0`.

## Bộ cài Windows (đề xuất)

[Tải lunainstaller.exe](https://github.com/17thedevv/luna/releases/download/v0.1.0-alpha.1/lunainstaller.exe) · [SHA-256](https://github.com/17thedevv/luna/releases/download/v0.1.0-alpha.1/lunainstaller.exe.sha256)

Chạy bộ cài, chọn thư mục và giữ tùy chọn thêm Luna vào user PATH. Setup tự tải Luna, LLVM 18.1.8 và GNU/MinGW rồi kiểm SHA-256 trước khi giải nén. Không cần quyền admin hoặc Rust/Cargo. Cần Windows x86_64, Windows 10 1809 trở lên, Internet, khoảng 390 MB tải xuống và 1,5 GB cho các thành phần đã cài.

Mặc định cài tại `%LOCALAPPDATA%\Programs\Luna`. Mở **Luna Command Prompt** từ Start hoặc mở terminal mới rồi chạy `luna --version`. Gỡ cài qua Windows Settings → Apps → Luna. Bộ cài chưa có chữ ký số.

Trong PowerShell, có thể kiểm setup trước khi chạy bằng `Get-FileHash .\lunainstaller.exe -Algorithm SHA256`, so sánh với file `.sha256` bên trên.

Để thử ví dụ với vị trí cài mặc định:

```powershell
$package = "$env:LOCALAPPDATA\Programs\Luna\packages\luna-0.1.0-alpha.1-x86_64-pc-windows-gnu"
Copy-Item "$package\examples\quickstart.ln" .
luna run .\quickstart.ln --quiet
$LASTEXITCODE
```

Nếu chọn thư mục khác, thay đường dẫn `$package` tương ứng. Ví dụ kết thúc với mã `0`.

## ZIP portable

| Nền tảng | Gói tải | Chương trình trong ZIP |
|---|---|---|
| Windows x86_64 GNU | [Tải ZIP Windows](https://github.com/17thedevv/luna/releases/download/v0.1.0-alpha.1/luna-0.1.0-alpha.1-x86_64-pc-windows-gnu.zip) | `bin/luna.exe` |
| Ubuntu 24.04 x86_64 GNU | [Tải ZIP Ubuntu](https://github.com/17thedevv/luna/releases/download/v0.1.0-alpha.1/luna-0.1.0-alpha.1-x86_64-unknown-linux-gnu.zip) | `bin/luna` |

[SHA256SUMS](https://github.com/17thedevv/luna/releases/download/v0.1.0-alpha.1/SHA256SUMS) · [Release notes](https://github.com/17thedevv/luna/releases/tag/v0.1.0-alpha.1)

ZIP Windows chứa compiler `.exe`, runtime và các artifact thư viện chuẩn. Giữ `bin`, `runtime` và `libs/external` cùng nhau sau khi giải nén. Không cần Rust/Cargo để dùng các gói này.

## Yêu cầu cho ZIP portable

- Cả hai nền tảng cần **LLVM 18** và **GNU C/C++ toolchain x86_64** bản địa.
- Windows cần `LLVM-C.dll` trên `PATH` và [Microsoft Visual C++ runtime x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). [Bản phân phối LLVM 18.1.8 chính thức](https://github.com/llvm/llvm-project/releases/tag/llvmorg-18.1.8), `clang+llvm-18.1.8-x86_64-pc-windows-msvc.tar.xz`, có các công cụ và DLL cần thiết. Đặt `LLVM_HOME` vào thư mục đã giải nén có chứa `bin`.
- Trên Ubuntu 24.04, cài `build-essential`, `llvm-18` và `unzip`.

LLVM và GNU là công cụ bên ngoài, không đi kèm ZIP Luna. Release này chưa có gói đã qualify cho macOS, ARM hoặc các nền tảng khác.

## Kiểm tra, giải nén và chạy

Tải ZIP đúng nền tảng và `SHA256SUMS` vào cùng một thư mục có quyền ghi.

<Tabs>
  <TabItem label="Windows PowerShell">
    So sánh hash bên dưới với dòng Windows trong `SHA256SUMS`:

    ```powershell
    Get-FileHash .\luna-0.1.0-alpha.1-x86_64-pc-windows-gnu.zip -Algorithm SHA256
    Expand-Archive .\luna-0.1.0-alpha.1-x86_64-pc-windows-gnu.zip -DestinationPath .
    $lunaPackage = (Resolve-Path .\luna-0.1.0-alpha.1-x86_64-pc-windows-gnu).Path

    # Thay đường dẫn LLVM/GNU bằng vị trí đã cài trên máy.
    $env:LLVM_HOME = 'C:\LLVM18'
    $env:PATH = "$lunaPackage\bin;$env:LLVM_HOME\bin;C:\mingw64\bin;$env:PATH"

    luna --version
    luna build "$lunaPackage\examples\quickstart.ln" -o .\quickstart.exe
    .\quickstart.exe
    $LASTEXITCODE
    luna build "$lunaPackage\examples\stdlib.ln" -o .\stdlib.exe
    .\stdlib.exe
    $LASTEXITCODE
    ```
  </TabItem>
  <TabItem label="Ubuntu 24.04">
    ```bash
    sudo apt-get install build-essential llvm-18 unzip
    sha256sum -c SHA256SUMS --ignore-missing
    unzip luna-0.1.0-alpha.1-x86_64-unknown-linux-gnu.zip
    export LUNA_HOME="$PWD/luna-0.1.0-alpha.1-x86_64-unknown-linux-gnu"
    export LLVM_HOME=/usr/lib/llvm-18
    export PATH="$LUNA_HOME/bin:$LLVM_HOME/bin:$PATH"
    chmod +x "$LUNA_HOME/bin/luna"

    luna --version
    luna build "$LUNA_HOME/examples/quickstart.ln" -o quickstart
    ./quickstart
    echo $?
    luna build "$LUNA_HOME/examples/stdlib.ln" -o stdlib
    ./stdlib
    echo $?
    ```
  </TabItem>
</Tabs>

`luna --version` in ra `luna 0.1.0`; manifest của gói ghi rõ đây là bản alpha. Cả hai ví dụ đều kết thúc với mã thoát `0`, không yêu cầu in ra console.

<Aside type="note">
  Xóa các override `LUNA_SYSROOT` và `LUNA_RUNTIME_LIB` cũ trước khi dùng gói. Compiler tìm runtime và 49 provider chuẩn theo vị trí của chính nó. Lỗi thiếu `LLVM-C.dll` trên Windows nghĩa là LLVM chưa có trên `PATH`.
</Aside>

## Dự án của bạn

Chép `examples/quickstart.ln` vào thư mục dự án có quyền ghi, chỉnh sửa rồi dùng `luna build` hoặc `luna run`. File `stdlib.ln` trong gói minh họa `import <vec>;` tường minh và chạy bằng artifact thư viện của gói.

Tiếp tục với [Khám phá ngôn ngữ](/vi/language-tour/) hoặc [Thư viện chuẩn](/vi/stdlib/). Nếu phát triển từ source, xem [hướng dẫn build trong repository](https://github.com/17thedevv/luna#build-and-verify).
