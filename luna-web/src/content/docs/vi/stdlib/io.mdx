## Hello world

Import provider `io`, rồi dùng `println_str` khi in string literal:

```luna
import <io>;

fn main() -> i32 {
    std::io::println_str("hello world");
    return 0;
}
```

Trong project Lunar, lưu vào `src/main.ln` rồi chạy `lunar run`.
Với file độc lập, dùng `luna run hello.ln`.

## Macro console đã có sẵn

Provider `io` cũng export `std::print!`, `std::println!`, `std::eprint!` và
`std::eprintln!`, cùng các tên tương ứng không có tiền tố `std::`.
Chúng in giá trị qua trait `Display` thông thường. Dấu `!` chọn macro;
hàm nhận byte slice `std::io::println(...)` là API riêng.

```luna
import <io>;

fn main() -> i32 {
    std::println!("hello world");
    std::println!("value: ", 42);
    return 0;
}
```

Ví dụ in `hello world` và `value: 42` trên hai dòng. Các rule macro hiện nhận
từ một đến bốn giá trị, in liên tiếp và không tự thêm dấu phân cách.
Macro xuống dòng còn nhận lời gọi không có đối số để in một dòng trống.

## Phân biệt văn bản và byte

| Hàm | Đầu vào | Đầu ra |
| --- | --- | --- |
| `std::io::print_str(text)` | `str`, gồm cả string literal | stdout, không xuống dòng |
| `std::io::println_str(text)` | `str` | stdout, có xuống dòng |
| `std::io::eprint_str(text)` | `str` | stderr, không xuống dòng |
| `std::io::eprintln_str(text)` | `str` | stderr, có xuống dòng |
| `std::io::print(bytes)` | `&[u8]` | stdout, đúng số byte của slice |
| `std::io::println(bytes)` | `&[u8]` | byte ra stdout rồi xuống dòng |

`str` của Luna là biểu diễn văn bản tĩnh kết thúc bằng NUL. Các hàm `_str`
dừng ở ký tự NUL kết thúc. `std::String` sở hữu dữ liệu và cung cấp
`as_bytes()` để truyền cho nhóm hàm nhận byte slice:

```luna
import <io>;
import <string>;

fn main() -> i32 {
    dec text = std::string_from_str("hello world");
    std::io::println(text.as_bytes());
    return 0;
}
```

`std::io::println("hello world")` sai kiểu vì literal `str` không phải byte
slice được mượn. Thêm `&` vào literal cũng không biến nó thành byte slice.
Dùng `println_str` hoặc truyền một giá trị `&[u8]` thực sự.

## Phạm vi formatting

Các hàm trên không xử lý format string. Lời gọi
`std::io::println("giá trị: {}", value)` và các format specifier kiểu printf
chưa được API này hỗ trợ. Macro console hiện cũng coi dấu ngoặc nhọn là ký tự
thường: `std::println!("value: {}", 42)` in `value: {}42`. Dùng
`std::println!("value: ", 42)` để in liên tiếp. Formatting foundation dùng trait thông thường
`std::fmt::Display` và `std::fmt::Writer`; nó không bao gồm interpolation hay
compiler tự chọn hàm in dựa trên tên.

## Đọc input và file

`std::io::read_line` nhận buffer `std::Vec<u8>` có thể sửa và trả về
`std::Result<usize, std::io::IoError>`; hàm không có dạng gọi không đối số.
Provider `file` cung cấp nhóm API whole-file riêng. Cần theo chữ ký đã khai báo,
không dùng các ví dụ kiểu Rust trước đây trên trang này.
