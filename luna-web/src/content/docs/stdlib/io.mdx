## Hello world

Import the `io` provider and call `println_str` for a string literal:

```luna
import <io>;

fn main() -> i32 {
    std::io::println_str("hello world");
    return 0;
}
```

In a Lunar project, save this as `src/main.ln` and run `lunar run`.
For a standalone file, use `luna run hello.ln`.

## Existing console macros

The `io` provider also exports `std::print!`, `std::println!`, `std::eprint!`
and `std::eprintln!`, with corresponding unqualified names. They format values
through the ordinary `Display` trait. The `!` selects a macro; the byte-slice
function `std::io::println(...)` is a separate API.

```luna
import <io>;

fn main() -> i32 {
    std::println!("hello world");
    std::println!("value: ", 42);
    return 0;
}
```

This prints `hello world` and `value: 42` on separate lines. Current macro rules
accept one to four values, written consecutively without an automatic separator.
The newline macros also accept no arguments to print an empty line.

## Text and bytes are different APIs

| Function | Input | Output |
| --- | --- | --- |
| `std::io::print_str(text)` | `str`, including a string literal | stdout, without a newline |
| `std::io::println_str(text)` | `str` | stdout, with a newline |
| `std::io::eprint_str(text)` | `str` | stderr, without a newline |
| `std::io::eprintln_str(text)` | `str` | stderr, with a newline |
| `std::io::print(bytes)` | `&[u8]` | stdout, exactly the byte-slice length |
| `std::io::println(bytes)` | `&[u8]` | stdout bytes followed by a newline |

Luna's `str` is the static NUL-terminated text representation. The `_str`
functions stop at its NUL terminator. An owned `std::String` provides
`as_bytes()` for the byte-slice functions:

```luna
import <io>;
import <string>;

fn main() -> i32 {
    dec text = std::string_from_str("hello world");
    std::io::println(text.as_bytes());
    return 0;
}
```

`std::io::println("hello world")` is a type error: a `str` literal is not a
borrowed byte slice. Adding `&` to the literal does not convert it into bytes.
Use `println_str` or pass an actual `&[u8]`.

## Formatting boundary

These functions do not parse format strings. Calls such as
`std::io::println("value: {}", value)` and printf-style format specifiers are
not supported by this API. Existing console macros also treat braces literally:
`std::println!("value: {}", 42)` prints `value: {}42`. Use
`std::println!("value: ", 42)` for sequential output. The formatting foundation uses ordinary
`std::fmt::Display` and `std::fmt::Writer` traits; compiler-selected print
callees and format-string interpolation are not part of that contract.

## Input and files

`std::io::read_line` takes a mutable `std::Vec<u8>` buffer and returns
`std::Result<usize, std::io::IoError>`; it is not a zero-argument function.
The `file` provider supplies the separate whole-file APIs. Consult their
declared signatures rather than the superseded Rust-style examples.
