has exactly one owning phase and no other phase may emit it. The canonical
registry assigns `InvalidAnnotation` / E0005 to Parser (lines 44, 112 and 132).
Attribute grammar in the range description does not waive that rule.

The driver calls `luna_semantic::AttributeProcessor::process_items` after
parsing (`luna-driver/src/lib.rs:273–274`, 379–380, 561–562); the processor returns
`Err(diagnostics)` when validation fails. This is the actual observed origin
of the reserved-symbol examples, preceding Resolver. Independently,
`luna-semantic/src/resolver.rs:438–526,576` constructs E0005 during trusted
language-item validation and namespace validation. TypeChecker constructs the

Parser itself still legitimately emits E0005 for malformed annotation syntax
(`luna-parser/src/lib.rs:35`). This is shared emission across phases, not merely
the physical location of a parser helper in another crate.

## Repair alternatives for maintainer review

1. Preserve Parser ownership and E0005 identity, moving grammar/static
   annotation validation to a parser-owned boundary. Reserved declarations
   can also be generated by macros; provider AST loading and trusted language
   items must retain equivalent validation. A partial move of these examples
   does not address Resolver's trust/identity checks or TypeChecker's resolved
   signature checks. Those need an approved mapping to semantic diagnostics.
2. Adopt semantic codes for contextual invalid declarations and attributes,
   preserving E0005 for parser grammar errors. The mapping changes observable
   code identities and must be adopted before implementation/tests change.
3. Amend the ownership model/registry to define annotation validation as its
   own authority, with explicit boundaries. This changes the frozen public
   diagnostic contract and cannot be decided autonomously.

Forwarding semantic failures through a parser-named reporting function would
not repair their origin. Global suppression, string matching, weakening
DIAG-8, or merely relabeling Stage 4 DONE are not repairs. The task explicitly
requires isolating work that needs public diagnostic ownership decisions.
